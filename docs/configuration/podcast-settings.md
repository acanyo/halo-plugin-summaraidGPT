# 播客听读

配置组：`podcast`。在「智阅 AI → 设置 → 播客听读」配置，在「播客听读」页签制作和预览。

讨论稿由 Halo AI Foundation 的语言模型编写，语音通过独立服务合成，音频保存到 Halo 附件库。

## 接入渠道

| 渠道 | 模型示例 | 配置说明 |
| --- | --- | --- |
| 阿里百炼 | `qwen-audio-3.1-tts-flash`、`cosyvoice-v3-flash`、`MiniMax/speech-2.8-turbo` | 统一使用北京地域百炼 API Key 与业务空间 ID，在下拉框中选择模型。 |
| MiniMax · 直连 | `speech-2.8-*`、`speech-2.6-*`、`speech-02-*`、`speech-01-*` | MiniMax 中国站 API Key，使用 `https://api.minimax.cn/v1/t2a_v2`。 |
| 豆包 · 原生双人播客 | 无需填写模型 ID | 豆包语音 API Key，需开通播客资源 `volc.service_type.10050`。 |

地域、密钥、业务空间和音色授权必须匹配。两个不同的音色分别对应主持人 A（提问）和 B（解释），可填写所选服务已授权的系统音色 ID。凭证保存在 Halo Secret 中，仅由服务端读取；设置页返回占位符，普通插件配置、公开接口与文章播放器不返回凭证。清空密钥并保存会删除该渠道的密钥。查看、修改配置需要 Halo 插件设置权限。

旧版的「阿里百炼 · CosyVoice」和「阿里百炼 · MiniMax」会在设置页统一显示为「阿里百炼」。保存时迁移所选渠道的凭证，保留旧配置及旧凭证；无需重新填写 API Key。

百炼各模型共用认证方式，但接口路径及音频、音色、情感参数有差异：Qwen/CosyVoice 使用 `audio/tts/SpeechSynthesizer`，MiniMax 使用 `aigc/multimodal-generation/generation`。插件会按模型转换请求，不能直接互换底层参数。

## 使用流程

1. 启用播客听读，选择讨论稿语言模型；留空沿用插件主模型或 AI 基座默认模型。
2. 选择语音渠道，填写密钥、模型、两个不同的音色，并选择供访客访问的附件存储策略。
3. 保存设置，在播客页选择文章、约 1～3 分钟的目标时长，以及轻松交流或深入解读风格；也可输入最多 200 字的自定义风格描述。
4. 生成讨论稿，阅读并编辑台词，保存后再点击「合成双人播客」。合成会调用付费语音服务。
5. 后台试听；启用文章页播放器后，已发布且公开的文章可直接收听。支持暂停、进度、倍速和点击对话稿跳转。

每轮不超过 300 字，4～40 轮、总计不超过 1800 字，两位主持人均需发言。时长通过稿件字数控制，实际音频会随语速和停顿变化。编稿读取已发布正文的前 24,000 字符，没有已发布正文的文章无法编稿。

## 模型、声音与情感

「讨论风格」控制文稿的内容和写法；「说话风格」控制声音如何表达，两项独立设置。

- **语音模型**：百炼模型下拉框包含 Qwen-Audio、CosyVoice 和 MiniMax；MiniMax 直连显示该渠道兼容的模型。切换模型会替换不兼容的系统音色及属于其他模型的复刻音色。其他自定义音色 ID 请确认在新模型下已授权。
- **主持人音色**：可选择已核对的系统音色，或输入音色 ID 后按回车确认。CosyVoice V3.5 仅使用复刻或设计音色，需要填写实际已授权且以目标模型 ID 加连字符开头的音色 ID，例如 `cosyvoice-v3.5-plus-`。
- **说话风格**：仅在两位主持人的音色均支持自然语言指令时显示，可下拉选择预设或输入自定义描述。Qwen 最多 200 字；CosyVoice 与情感指令合并后最多 100 字符，汉字按 2 字符计算。
- **语音情感**：仅提供模型和两位主持人均支持的选项。CosyVoice 系统音色的固定情感指令由插件按音色格式生成；MiniMax 使用其情感参数。
- **合成语种**：按模型与两位主持人的音色能力取交集，留空自动识别。此设置引导发音，不翻译讨论稿。
- **自动情感标注**：默认关闭。开启后，生成新讨论稿时会为每轮选择情感；支持富语言标签的 Qwen 与部分 MiniMax 模型还可添加少量笑声、叹息等语气。生成后可逐轮调整，再合成音频。

不支持情感或指令的模型会隐藏相应设置。切换模型或音色时会清除不兼容的情感、说话风格和语种，避免把某个模型的专用参数发送给其他模型。修改这些默认设置不会重写已有讨论稿。

## 渠道与模型能力

模型目录与音色目录由前后端共用，切换渠道会使用该渠道的模型和能力：

| 系列 | 可选模型 | 表达控制 |
| --- | --- | --- |
| 百炼 Qwen-Audio | 3.1 Flash、3.0 Plus、3.0 Flash | 自然语言指令、情感与全部官方富语言标签；英文音色等特殊音色按自身能力限制。 |
| 百炼 CosyVoice | V3 Flash、V3 Plus、V2、V3.5 Flash、V3.5 Plus | 系统音色按固定情感格式控制；支持自然语言指令的复刻/设计音色可输入风格；V2 不发送情感指令。 |
| 百炼 MiniMax | 2.8 Turbo/HD、02 Turbo/HD | 情感与语种按百炼接口约束适配。 |
| MiniMax 直连 | 2.8、2.6、02、01，各含 Turbo/HD | 2.6 额外支持流畅、低声；2.8 支持拟声；01/02 不提供菲律宾语、波斯语和泰米尔语。 |

Qwen 与 CosyVoice 下拉框包含官方文档公布的系统音色；MiniMax 直连提供官方系统音色列表，百炼保留已核对的系统音色，并均支持输入账户已授权的其他音色 ID。系统音色及能力随服务商更新时需同步目录。

同名 MiniMax 模型在直连与百炼的能力不能混用，例如 `speech-02-*` 的低声情感仅在百炼提供。全稿会在首次语音请求前校验，不兼容的逐轮情感或拟声需先清除。

## 豆包原生双人播客

豆包使用已确认的讨论稿直接合成（原生接口 `action=3`），无需填写模型 ID。使用豆包语音控制台的 API Key，并开通播客资源 `volc.service_type.10050`。

- 两位主持人的音色支持下拉选择官方播客音色：黑猫侦探社男声、咪仔同学、刘飞、潇磊。也可输入已授权且兼容原生播客接口的其他音色 ID，两个主持人必须使用不同音色。需要额外 `speaker_additions` 的高级复刻配置暂未开放。
- 「播客语速」使用原生 `audio_config.speech_rate`，整数范围 -50～100：0 为正常语速，-50 约为 0.5 倍速，100 约为 2 倍速。该设置在生成音频时生效，与播放器倍速独立。

原生播客服务处理双人表达，不接受本插件为其他渠道提供的逐轮情感、语气词、自然语言语音指令与合成语种选项。保存或编辑过此类字段的讨论稿，切换到豆包后需先清除，界面和服务端会校验。

## 固定开场白与结束语

在「智阅 AI → 设置 → 播客听读」的「讨论风格」下方，可填写「固定开场白」与「固定结束语」，每项最多 300 字，默认留空，留空时不添加。

生成新讨论稿时，开场白自动成为第一轮，结束语自动成为最后一轮，均由主持人 A 朗读。添加后的台词会进入讨论稿编辑器，可预览、修改并保存后再合成音频。固定话术计入总计 1800 字与 40 轮的限制。

修改设置不会自动更改已有讨论稿或音频，重新生成讨论稿时才会应用。

## 存储与任务

- 统一保存为 24kHz、16-bit、单声道 WAV，服务器无需 FFmpeg；3 分钟约 8.6MB，另计附件存储和播放流量。
- Qwen、CosyVoice、MiniMax 逐轮合成并加入短暂停顿；豆包一次提交完整对话稿到原生播客接口。
- 仅有播客管理权限的账号可手动生成，访客访问和重复播放不会重新合成。
- 同一文章任务互斥；失败后保留讨论稿和旧音频，不自动重试付费调用。服务重启会标记中断任务，需手动重试。
- 文章或讨论稿更新时后台提示更新，旧音频继续可用，直到新音频合成成功。
- 重新生成或移除播客不会删除历史音频附件，可在 Halo 附件库自行清理。

## 合成失败排查

CosyVoice 返回 `BadRequest.IllegalEndpoint` 时，表示业务空间端点无效。请在百炼北京地域核对业务空间 ID，并确认 API Key 属于同一业务空间；这类错误不能通过充值解决。更正配置后，可使用已保存的讨论稿重新合成。插件只显示固定的错误说明，不透传语音服务的响应原文或凭证。
