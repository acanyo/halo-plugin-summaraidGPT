# MCP 服务

配置组：`mcp`。入口：智阅 AI 工作台 → **MCP 工具**。这是独立的服务管理页；旧的设置链接会自动跳转。

MCP 将外部搜索、文档检索或业务查询工具接入前台助手。模型根据问题选择已开放的工具，后端连接服务，前台显示调用状态和结果卡片。

## 配置步骤

1. 在「Agent 能力」中开启站点操作 Agent，并将前台助手设为包含 Agent 的显示模式。
2. 在「MCP 工具」添加服务，填写服务名称和完整 Streamable HTTP 地址，例如 `https://example.com/mcp`。空白页也提供 Cloudflare 公开只读文档服务示例。
3. 按服务要求填写 Bearer Token 或自定义请求头。无需鉴权时可留空。
4. 点击「连接并发现工具」。在「工具与访问」中搜索、筛选并勾选要开放的工具，也可批量开放或关闭筛选结果。
5. 设置各工具的「执行前确认」与「仅登录用户」，在「聊天入口与示例问题」填写展示名称和示例问题。
6. 启用服务和 MCP 总开关，点击「保存修改」。未保存的编辑离开页面前会提醒，可撤销修改。

新发现的工具默认关闭，默认要求执行前确认。刷新工具列表保留同名工具已有的访问策略，并移除服务已不再提供的工具。仅勾选工具还不足以生效，MCP 总开关、对应服务和 Agent 都需要启用。

## 服务连接

| 配置 | 说明 |
| --- | --- |
| MCP 地址 | 完整的 HTTP(S) Streamable HTTP 端点，支持 JSON 与 SSE 响应。 |
| Bearer Token | 后端使用 `Authorization: Bearer …` 连接服务。 |
| 自定义请求头 | 可配置 `X-API-Key` 等鉴权字段；协议及连接保留请求头不可覆盖。 |
| 超时 | 每个服务 3–60 秒，默认 20 秒。 |
| 允许本机或内网服务 | 默认关闭。启用后可连接 Halo 运行环境中的本机或内网地址；容器的 localhost 指向容器自身。 |

第一版提供远程 Streamable HTTP 工具接入，不启动 stdio 子进程，不提供 OAuth 登录流程，也不自动加载 MCP Resources、Prompts 或 MCP Apps。服务鉴权请使用站长配置的 Token / 请求头，URL 不接受账号、密码或查询参数。连接不跟随重定向。

最多配置 8 个服务，每个服务最多发现 200 个工具，每轮聊天最多添加 64 个 MCP 工具。连接按需建立并在操作结束后关闭；单个服务不可用时保留其他工具和普通聊天能力。

## 前台展示与访问

- 前台支持调用中、等待确认、完成、取消和失败状态。
- 文本、图片、资源链接、结构化搜索列表和对象数组表格显示在可展开的结果卡片中。
- 图片在前台展示，助手基于工具返回的文字和结构化数据回答。
- 文本、图片和结构化数据有长度限制；过长结果会提示已截断。图片仅支持 PNG、JPEG、WebP、GIF。
- 聊天的「可用工具」展示当前访问者能使用的工具。点击后填入示例问题，编辑并发送后由助手选择调用。
- 最终回答、工具状态、文字、结构化结果和来源链接保存在会话记录中，刷新后恢复卡片并支持继续追问；后台「会话记录」也可展开查看工具结果。
- 历史每轮最多保留 16 张卡片，合计约 256 KB；单张图片超过约 96 KB 时保留提示与文字。恢复的历史仅将文字和工具资料交给模型，不携带图片或可执行的待确认操作。
- 刷新时尚未完成的调用显示为已中断，不自动执行；重新提问可再次发起。
- MCP 凭证与完整服务配置不进入公开的 `dialogConfig`。公开工具调用仍受现有 Agent 访问模式、来源校验和限流约束。
- 工具停用后，待执行调用会重新检查授权。需用户确认的工具要求模型支持原生工具调用，文本协议兼容模式不会执行这类操作。

管理员可直接配置。委派给其他账号时，使用「管理 MCP 服务」角色模板，可管理服务、发现工具和查看调用记录；API 由 Halo 后端权限控制。

## 调用记录与性能

服务右侧的「调用记录」及左侧「全部调用记录」展示工具发现、工具调用的结果、耗时、时间和失败原因，可按操作或成功状态筛选、翻页。记录不包含服务凭证、提问参数或工具返回正文。

工具目录缓存 5 分钟，同一服务的并发发现合并为一次请求；失败短暂缓存 10 秒。修改连接信息立即清除对应目录缓存，修改工具名称或访问策略会沿用目录；执行时仍检查最新授权。「刷新工具」可强制重新发现。进程重启会清空目录缓存，历史调用记录和会话结果仍保留。

MCP 工具使用站长配置的服务凭证。向匿名用户开放某个工具，意味着允许访客通过助手使用该工具；请依据服务实际的数据范围选择开放项。
