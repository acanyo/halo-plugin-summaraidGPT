# 热词注释

在工作台的「热词注释」页面选择一篇已公开发布的文章，点击「识别热词」。AI 会识别生僻词、专业术语、缩写等，结合本文上下文生成通俗解释。使用「AI 设置」中的摘要模型，未单独配置时使用默认文本模型。

预览后在「设置 → 热词注释」开启「启用热词注释」，文章正文中的词语会出现点状下划线。读者悬停、点击或用键盘聚焦即可查看解释，点击其他位置或按 Escape 关闭。

| 设置 | 默认值 | 作用 |
| --- | --- | --- |
| 启用热词注释 | 关闭 | 控制文章页自动生成与注释展示。后台仍可手动生成预览。 |
| 访问文章时自动生成 | 开启 | 访问文章时在后台识别热词；关闭后仅使用手动生成的结果。 |
| 每篇最多解释词数 | 8 | 可设置 1–15 个；没有需要解释的词时不强行生成。 |

结果按文章保存，正文、标题或最多词数变化后旧结果不再展示，下次自动或手动生成会更新。首次生成在后台进行，不阻塞正文加载，当前页面会等待约 100 秒获取结果。失败后自动生成等待 5 分钟再重试；可在后台立即重新生成。

每词只在正文首次出现时标记，跳过代码块、链接、标题、编辑区以及插件自身的组件。仅分析已公开发布的正文，最多读取前 16000 字；不修改原文，不为草稿、私密或加密文章提供公开词语数据。AI 解释可能存在偏差，应结合文章理解。

公开接口只读取已有注释，不向访客开放重新生成。手动生成需要 Halo 的「管理智阅 AI 助手」权限，并执行后台登录、来源和限流校验。
