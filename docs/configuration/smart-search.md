# 智能搜索

先启用 Halo 官方搜索组件，再在 **智阅 → 设置 → 站点体验 → 智能搜索** 中启用扩展。保存后刷新前台页面。

扩展保留官方弹窗、输入框、关键词结果、历史记录和底栏，在输入框下增加「智能搜索 / AI 解答」两个轻量入口。点击后才展开补充内容，收起后恢复原搜索列表。颜色、字体跟随官方组件和主题。

- **关键词**：继续由官方组件处理，搜索行为、结果高亮、历史记录和键盘导航保持原样。
- **智能搜索**：在原输入框中描述问题，再点击「智能搜索」。复用知识库混合检索与精排；输入过程中不调用模型。无匹配或模型不可用时显示关键词结果，并说明回退原因。
- **AI 解答**：点击后流式整理公开文章中的信息，完成后显示引用来源。可以停止生成；修改问题、关闭搜索框会取消在途请求。
- **随机推荐 / 热门文章**：未输入关键词时显示在「最近搜索」上方，各展示最多 3 篇公开发布的文章。随机推荐支持「换一批」，文章充足时避开上一批；热门文章按 Halo 累计阅读量降序展示。点击标题直接阅读，输入关键词后自动收起。推荐遵循主题的作者、分类、标签等搜索范围，排除私密、草稿、已删除及隐藏列表文章，不调用 AI 模型。

## 准备知识库

在 **知识库** 中启用 RAG，导入已公开发布的文章，并完成索引。智能搜索使用已有的向量、精排模型，回答使用 AI 设置中的知识库问答模型。

智能搜索目前只使用知识库中对应 Halo 公开文章的片段。每次检索都会检查原文章是否仍公开、已发布且未删除，并核对片段是否仍存在于当前发布正文；校验发生在精排和回答模型调用之前。手动文档、Docsme 文档、草稿、私密和加密文章不会进入智能搜索的语义结果和回答。更新文章后，应重新导入并更新索引，以获得完整的最新结果。

AI 请求沿用 AI 设置中的登录要求、来源校验与限流。关键词搜索保持公开可用。

知识库尚未就绪、关闭或向量服务暂时不可用时，AI 解答会使用 Halo 关键词搜索找到的公开文章作为依据，并重新读取当前发布正文。两种方式都没有找到公开依据时，直接提示资料不足，不调用回答模型。

## 主题入口

继续使用主题原有的 `SearchWidget.open(options)`，扩展不接管它的 `open` 属性，也不替换原弹窗。扩展读取当前 `search-form` 的输入及 `options`，因此保留内容类型、作者、分类和标签条件。

主题也可以调用以下辅助方法，打开的仍是官方搜索框：

```html
<button onclick="SummaraidSearch.open()">搜索</button>
<button onclick="SummaraidSearch.open({includeTagNames: ['tag-name']})">搜索指定标签</button>
```

扩展目前适配官方搜索组件 1.7.1 的 `search-modal` / `search-form` 结构；没有识别到支持的结构时保留官方搜索。快捷键、关闭和结果导航由官方组件或主题提供。未安装官方组件时不会创建替代弹窗或悬浮按钮。

关闭智能搜索扩展并刷新页面，原搜索框继续正常使用。
