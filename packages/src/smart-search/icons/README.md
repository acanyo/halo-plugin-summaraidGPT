# Search icons

Original SVG paths from **Remix Icon 4.8.0**, copied from the project's installed
`@iconify/json` 2.2.454 collection (`json/ri.json`). Paths are unchanged; the SVG
wrappers add accessibility attributes and an Iconify identifier. Vite bundles
these local SVGs with the search widget.

Source: https://github.com/cyberalien/RemixIcon

License: Apache-2.0, retained in `LICENSE` and in the plugin's packaged
`META-INF/licenses/remix-icon-LICENSE.txt`.

| UI | Iconify identifier |
| --- | --- |
| Semantic search | `ri:search-eye-line` |
| AI answer | `ri:sparkling-2-line` |
| Collapse | `ri:arrow-up-s-line` |
| Article | `ri:file-text-line` |
| Open link | `ri:arrow-right-up-line` |
| Stop generation | `ri:stop-circle-line` |
| Random recommendations | `ri:shuffle-line` |
| Popular articles | `ri:fire-line` |
| Refresh recommendations | `ri:refresh-line` |
| Reading count | `ri:eye-line` |
